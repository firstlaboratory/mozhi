# Mozhi

Learn Tamil, Hindi, Malayalam, English and Spanish — from any of them — and translate everyday slang.

- Lessons with quizzes, listening, word ordering and speaking practice
- Script trainer (Tamil, Hindi, Malayalam) and grammar notes
- Spaced-repetition flashcards, XP, streaks and a daily goal
- Real-life conversation scenes and AI role-play
- Slang-aware translator (Tanglish, Hinglish, Manglish…) powered by Gemini

Works offline for lessons and review. The translator, AI lessons and role-play need internet and a free Gemini API key
(from aistudio.google.com/apikey), which is stored only on your device.

Install: open the site in Chrome on Android → ⋮ → Add to Home screen.
